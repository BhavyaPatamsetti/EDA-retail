# Retail Exploratory Data Analysis

A notebook investigating retail sales, profit, customer segments, product categories, and regional patterns.

## What is included

- Uses pandas, NumPy, seaborn, and matplotlib to inspect and visualize retail data.

## Getting started

Use Python and JupyterLab. Create an isolated environment, install the libraries imported by the notebook, then launch `jupyter lab` from this repository. Open the notebook and run cells from top to bottom after configuring the input data paths. No dependency lockfile is provided.

## Repository guide

- `Exploratory Data Analysis - Retail.ipynb`
- `README.md`
- `Retail(Dataset).csv`

## Limitations and reproducibility

The notebook expects `Retail(Dataset).csv`; provide that file or update its path. Visual relationships are exploratory and do not establish causal explanations.
